# Cutting Board Designer

Workshop tool for end-grain and edge-grain cutting boards. Pick species, set strip widths, preview the glue-up, and print a cut / buy list.

## Run

```bash
npm install
npm run dev
```

## Test and build

```bash
npm test
npm run build
```

The repo ships a Coolify-friendly Docker image (`Dockerfile` + nginx) for static deploy. Local container: `docker compose up --build` on port 3080.
